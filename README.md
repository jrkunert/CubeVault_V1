# CubeVault

> A governed, enterprise-grade platform for managing and extending OneStream solutions.

## Overview

CubeVault is an enterprise software project designed to provide a modular, maintainable, and extensible platform for OneStream-related tools and services.

The project follows a governance-first approach. Before implementation began, the project established a complete documentation baseline covering governance, architecture, engineering standards, and recovery.

Current Status: **Milestone 1 – Architecture Validation & Platform Foundation**

---

## Documentation

The following documents define the project baseline.

| Document | Purpose |
|----------|---------|
| Constitution | Governing principles and document authority |
| Project Manifest | Project scope, objectives, and operational definition |
| Architecture Guide | Approved architectural baseline |
| Engineering Standards | Development methodology and engineering practices |
| Recovery Package | Milestone history and project continuity |

Documentation is located under the `docs` directory.
